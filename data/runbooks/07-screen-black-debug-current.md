# QNX Screen 仪表黑屏排查（新版）

状态：已发布  
版本：v2  
更新时间：2026-07-26  
适用平台：8155、8295、8397

先确认仪表应用进程存在，再使用项目诊断接口 `cluster-display probe` 检查 display、window 和 buffer 状态。QNX Screen 可承载硬件加速图形并驱动多个显示，因此排查时必须记录目标平台和显示拓扑，不能只判断应用是否存活。

若窗口未创建，采集应用启动日志；若窗口存在但没有提交缓冲，采集渲染线程状态；若缓冲已提交但屏幕无画面，转交显示/BSP负责人检查链路。不要直接重启整个显示服务，以免丢失现场。

`cluster-display` 为虚构项目工具。
