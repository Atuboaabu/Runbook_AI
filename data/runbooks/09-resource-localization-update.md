# 仪表主题与多语言资源更新

适用平台：8155、8295、8397；状态：已发布。

将图片、字体和翻译文件放入项目资源目录，执行 `cluster-assets validate --platform <平台>`。校验必须通过缺失键、字体授权、图片尺寸和内存预算检查。然后执行 `cluster-assets package --locale zh-CN,en-US` 生成资源包。

资源部署后切换中英文，检查长文本截断、单位显示、告警文案和右侧状态区布局。8295和8397项目还需按各自显示拓扑检查HUD测试页面；8155不得套用其他平台的资源预算。

负责人：HMI应用组；更新时间：2026-05-09。所有 `cluster-assets` 命令为虚构项目工具。
