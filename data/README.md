# 最小验证集

本目录中的内容均为虚构数据，用于 Runbook AI 的 RAG 与 Agent 开发测试。

## 组成

- `runbooks/`：10 份不同写法、不同完整度和不同状态的研发操作资料。
- `evaluation/questions.jsonl`：20 条验证问题及期望行为。

## 覆盖场景

- 正常检索与回答
- 环境不明确时追问
- 信息不足时拒答
- 新旧资料冲突与状态过滤
- 危险操作警告
- 非正式事件记录识别
- 引用来源验证

## 使用约束

所有域名均使用保留后缀 `.invalid`，系统名、人员和命令均为虚构。不要将示例命令用于真实环境。
