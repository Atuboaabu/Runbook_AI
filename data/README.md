# 汽车仪表应用开发最小验证集

本目录是 Runbook AI 的虚构测试语料，聚焦 QNX 汽车数字仪表应用开发，并以项目中的 8155、8295、8397 三类目标平台为检索维度。

## 组成

- `runbooks/`：10份不同写法、完整度、平台范围和生命周期状态的研发资料。
- `evaluation/questions.jsonl`：20条问题及期望行为。

## 覆盖主题

- QNX交叉编译环境
- 8155、8295、8397开发包部署差异
- QNX日志与崩溃信息采集
- QNX Screen黑屏排查
- 实验室CAN信号模拟
- 主题与多语言资源
- 应用开机自启动事件
- 新旧文档冲突、平台不明确、范围外问题和提示注入

## 真实性边界

QNX Screen、BSP、`pidin`、`slog2info`等名词用于构造接近实际研发语境的样本。所有 `cluster-*` 命令、输出、人员、项目流程和平台配置均为虚构，不能用于真实设备、车辆或量产环境。

8155、8295、8397在本数据集中只作为项目目标平台标签。没有公开依据的板级细节不会被描述为真实事实。
